# Data packages

Download the model and result packages from [Zenodo (10.5281/zenodo.23660866)](https://doi.org/10.5281/zenodo.23660866).

All packages are produced from the cluster project by `release_tools/cluster/build_release.py` (read-only on the project) and contain project-relative paths. Extract them into the repository root.

| Package | Content | Count | Size |
|---|---|---|---|
| Level-1 data (in git) | `data/aggregate_full/figure_source_data/*`, 10 Phase-F tables, `source_qualification.csv` | all figures | measured by `assemble_local.py` |
| P1_pretrained_checkpoints | `sources/nav_seed_61xx/artifacts/navigation/best.pt` (navigation, best validation loss), `sources/nav_seed_61xx/artifacts/sequence_control/best_validation.pt` (delayed reconstruction), training histories, historical identity records | 20 checkpoints, 100 files | 1,520,906,240 bytes |
| P2_target_checkpoints | frozen-core target models (interface and readout only): Phase F scalar gain (navigation, matched, fresh-random), E0.9a, E6 ρ series, E6 rescaling | 150 + 60 + 210 + 60 checkpoints | 1,019,033,600 bytes |
| P3_source_level_results | `rerun_best_validation/aggregate_full/*.csv|json`, 4 × 4 / factorial result rows, Phase-F and mechanism tables (cell `metrics.csv`, `per_length.csv`, collectors' `aggregate/`), topology summaries, split manifests, protocols | 11,041 files | 312,662,279 bytes (gzip archive) |

Synthetic training/test trials and navigation trajectories are generated by the released code using the recorded seeds and splitting procedures. Intermediate checkpoints, optimizer states and logs are not distributed.

Archive checksums are in the code repository at `data/PACKAGE_SHA256SUMS.txt`.

Package counts and sizes are in `data/PACKAGE_INVENTORY.json`. Data/model license: CC BY 4.0; software license: MIT.

The released navigation `best.pt` uses best-validation selection; the original navigation `source_identity.json` records describe an earlier balanced selection. Use `data/source_level_results/checkpoint_provenance/released_checkpoints.csv` for the actual released pretrained models, and `released_target_checkpoints.csv` in the same directory for target models.
