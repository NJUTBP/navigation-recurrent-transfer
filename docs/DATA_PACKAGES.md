# Data packages

Download the model and result packages from [Zenodo (10.5281/zenodo.23660866)](https://doi.org/10.5281/zenodo.23660866) and extract them into the repository root. They contain project-relative paths and were assembled by `release_tools/cluster/build_release.py` from the selections in `release_tools/cluster/release_manifest.json`.

| Package | Content | Count | Size |
|---|---|---|---|
| Level-1 data (in git) | `data/aggregate_full/figure_source_data/*`, 10 Phase-F tables, `source_qualification.csv` | all figures | see `data/RELEASE_FILES.json` |
| P1_pretrained_checkpoints | `sources/nav_seed_61xx/artifacts/navigation/best.pt` (navigation, best validation loss), `sources/nav_seed_61xx/artifacts/sequence_control/best_validation.pt` (delayed reconstruction), training histories, source identity records | 20 checkpoints, 100 files | 1,520,906,240 bytes |
| P2_target_checkpoints | frozen-core target models (interface and readout only): Phase F scalar gain (navigation, matched, fresh-random), E0.9a, E6 ρ series, E6 rescaling | 150 + 60 + 210 + 60 checkpoints | 1,019,033,600 bytes |
| P3_source_level_results | `rerun_best_validation/aggregate_full/*.csv|json`, 4 × 4 / factorial result rows, Phase-F and mechanism tables (cell `metrics.csv`, `per_length.csv`, collectors' `aggregate/`), topology summaries, split manifests, protocols | 11,041 files | 312,662,279 bytes (gzip archive) |

Layout after extraction:

```text
sources/nav_seed_<s>/artifacts/navigation/best.pt                    P1   navigation network of source s
sources/nav_seed_<s>/artifacts/sequence_control/best_validation.pt   P1   paired delayed-reconstruction network
sources/nav_seed_<s>/configs/, state/                                P3   per-source configurations and stage records
rerun_best_validation/aggregate_full/                                P3   4 x 4 aggregate tables
rerun_best_validation/sources/nav_seed_<s>/artifacts/                P3   4 x 4 and factorial result rows, topology summaries
rerun_best_validation/hard8x8_diagnostics/audit_v1/phaseF_fullscale_v1/   P2, P3   Phase F (8 x 8) cells and tables
rerun_best_validation/followups/mechanism_v1/<experiment>/           P2, P3   mechanistic analyses
```

Synthetic training and test trials and navigation trajectories are generated by the released code from the recorded seeds and splitting procedures. Intermediate checkpoints, optimizer states and logs are not distributed. Target checkpoints of the 4 × 4 experiments and the full-finetune 8 × 8 conditions are not part of P2.

Archive checksums are in `data/PACKAGE_SHA256SUMS.txt` (check with `python release_tools/local/verify_release.py --repo . --packages /path/to/packages`); package counts and sizes are in `data/PACKAGE_INVENTORY.json`. Data/model license: CC BY 4.0; software license: MIT.

## Checkpoint selection

The released navigation `best.pt` is the checkpoint with the lowest navigation validation loss. The `source_identity.json` records in P1 refer to a different checkpoint selection and do not identify the released files; use `data/source_level_results/checkpoint_provenance/released_checkpoints.csv` for the released pretrained models and `released_target_checkpoints.csv` in the same folder for the target models. Target checkpoints use the storage mode `frozen_core_omitted_reconstruct_from_origin_and_seed` and are loaded with `tools/reevaluation/reevaluation_common.py`.
